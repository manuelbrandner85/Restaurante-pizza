# Ristorante Boulevard — Agrigento

Website des Ristorante Boulevard, Agrigento (Sizilien).
Eine statische Seite, kein Server nötig.

## Aufbau
- `index.html` — die komplette Seite (HTML, CSS, JavaScript in einer Datei)
- `bilder/` — alle Fotos im WebP-Format

## Sprachen
Deutsch, Italienisch, Englisch. Die Texte stehen im Objekt `TEXTE`
am Ende von `index.html` — je ein Block pro Sprache mit denselben Schlüsseln.
Beim ersten Aufruf wählt die Seite die Browsersprache, oben rechts umschaltbar.

## Noch einzutragen
Adresse, Telefon, E-Mail, Öffnungszeiten sowie die Gerichte und Preise
unter „Alla carta" sind Platzhalter. Ebenso Inhaber und P. IVA im Impressum.
